# Chi Bene Chen

Academic homepage for Chi Bene Chen, PhD student in Automation at Tsinghua University.

The static homepage uses a responsive layout and visual styling adapted from [PRISM](https://github.com/xyjoey/PRISM). The upstream MIT license is preserved in `PRISM-LICENSE.txt`.

Edit `index.html` to update the content and `style.css` to change the appearance. `theme.js` handles the theme switch and section navigation. No build step is required.

To preview locally:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Open http://127.0.0.1:8765.
